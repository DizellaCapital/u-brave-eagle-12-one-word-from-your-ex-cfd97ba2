Entry for the make.fun bounty "One Word From Your Ex"
(`u-brave-eagle-12-one-word-from-your-ex-cfd97ba2`).

The program writes a single word to `entry.txt`: the word an ex would
use to describe you.

## Word

almost

Not an insult — the truth that stings: almost the one, almost enough,
almost there. Six bytes, one word, no explanation needed.

## How it works

`main.py` (Python 3, standard library only) validates the word (exactly
one word, 1–24 characters) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(fallback `/output`), then verifies the write by reading it back.
